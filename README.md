# Bubble Mind — Stage 1

A playful bubble-based mind-mapping prototype. Starts blank with **Begin an idea** and **Every universe begins with a thought.**

## Test

After GitHub Pages is enabled, open https://readyplayer99.github.io/BUBBLE-MIND/

Create a project bubble, enter it, create a child bubble, go back, rename test bubbles, and toggle movement. Data saves to this browser's local storage (not synced across devices).

## Publish

GitHub repository → Settings → Pages → **Deploy from a branch** → **main** → **/(root)** → Save. Wait for the Pages deployment to finish.

## Notes

This is Stage 1 only. Do not rely on this prototype for irreplaceable work: no export/restore system is included yet. No AI integration or full notes editor.
